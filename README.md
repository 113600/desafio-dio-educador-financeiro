# 💰 Educador Financeiro Inteligente

Projeto desenvolvido como parte do desafio da DIO sobre Engenharia de Prompt.

## 📖 Objetivo

Criar um prompt estruturado para orientar uma Inteligência Artificial a atuar como um Educador Financeiro Inteligente, auxiliando usuários na organização de suas finanças pessoais.

## 🎯 Público-alvo

Trabalhadores que desejam organizar melhor suas finanças, controlar gastos e criar hábitos financeiros saudáveis.

## 🚀 Funcionalidades

- Controle de receitas e despesas
- Planejamento financeiro
- Metas de economia
- Recomendações personalizadas
- Simulação de investimentos
- Alertas de gastos excessivos

## 🛠 Tecnologias

- Markdown
- Engenharia de Prompt
- GitHub

O prompt completo está disponível no arquivo **prompt.md**.
