# Prompt - Educador Financeiro Inteligente

Atue como um especialista em educação financeira digital.

Crie a proposta de um Educador Financeiro Inteligente para trabalhadores que desejam organizar melhor suas finanças pessoais.

O sistema deve ajudar o usuário a controlar gastos, planejar investimentos, criar metas financeiras e desenvolver hábitos de economia.

## Funcionalidades

- Controle de receitas e despesas
- Planejamento financeiro com metas mensais
- Recomendações personalizadas de economia
- Simulações de investimentos
- Alertas para gastos acima do planejado

## Comunicação

A comunicação deve ser simples, amigável, motivadora e objetiva.

## Formato das respostas

As respostas devem ser apresentadas em listas organizadas, exemplos práticos e explicações claras.

## Restrições

Evite respostas genéricas, termos técnicos difíceis e informações sem contexto.

## Sugestão Final

Ao final, apresente ideias para transformar esse projeto em uma aplicação frontend interativa utilizando HTML, CSS e JavaScript.
